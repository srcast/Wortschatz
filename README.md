# Wortschatz

A simple web app for practising German–Portuguese vocabulary, organised by CEFR level (A1 to B2).

## Features

- **Four levels**: A1, A2, B1 and B2, each showing only the words introduced at that level.
- **Word types**: nouns (with article), verbs, adjectives, adverbs, prepositions (with the case they take) and connectors, with a filter to practise one type at a time.
- **Both directions**: German → Portuguese or Portuguese → German.
- **No repeats**: within a round, every word appears once before any repeats.
- **"Já sei" (I know it)**: hides words you already know; **Limpar** (Clear) brings them back for the current level.
- **Saved progress**: level, filter, direction and known words are remembered between sessions.
- **Works offline** once opened, and adapts to light and dark mode.

## Vocabulary

The A1–B1 word lists are based on the Goethe-Institut vocabulary lists. B2 is a custom selection, as there is no official list for that level.
